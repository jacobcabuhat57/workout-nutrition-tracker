# Workout and Nutrition Tracker

A Java command-line tool for tracking workouts, nutrition, and weekly progress.

## The Problem

I want an easier way to keep track of my workouts and nutrition.
Remembering what weight I used or what I ate makes it harder to
stay organized and see progress. I want everything in one place
so I can stay consistent with my strength and health goals.

## How It Works / MVP

The program will use a text menu where I can:

- Log exercises with the date, weight, sets, and reps.
- View previous workouts.
- Manually enter foods with calories, protein, carbs, and fat.
- View daily nutrition totals.
- Edit or delete incorrect entries.
- Save and load entries between sessions.
- View a basic weekly summary of workouts and nutrition.

## Planned Tech Stack

The project is currently in the planning stage.

## Usage

The planned workflow is to open the program, choose an option
from the menu, and enter workout or nutrition information.
The program will save entries so they can be viewed later.

Run commands and examples will be added after implementation.
